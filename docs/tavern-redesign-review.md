기준 운영 커밋: `bc054f9de77d326dd389a82d8c7d9d9dd6fc8eeb`.
운영 `main` 및 기존 `/preview/tavern/` 파일은 변경하지 않는다.

## 범위

- 첨부 `와포북 판타지 선술집 UI.png`를 기준으로 좌측 방송 목록, 중앙 로고/소개, 우측 소식/이벤트, 하단 20인 명단/현황을 구성했다. 목재와 양피지는 HTML 패널의 장식으로만 사용한다.
- 배경은 첨부 `inn-interior.webp`와 저장소의 `assets/inn-interior.webp`가 바이트 단위로 동일함을 확인하고 원본을 그대로 사용한다. 시안에서 배경을 잘라 쓰지 않는다.
- 공통 헤더는 실제 메뉴 8개, 검색 form, BGM 컨트롤로 구성한다. 모바일 메뉴와 키보드 Escape 닫기를 지원한다.
- 홈은 `tavern-home.js`와 `styles/tavern-redesign.css`의 전용 구조로 분리했다. 이전 홈과 헤더의 고정 좌표 규칙을 기존 스타일 파일에서 제거했다. 기존 책 내부의 규칙과 상세 함수는 유지한다.
- 이전 `assets/approved/home.webp`는 새 홈/헤더에서 사용하지 않는다. 하위 책에는 기존 양피지·카드·장식 에셋을 유지한다.
- 홈 20칸은 `data.slots`를 그대로 읽는다. 없는 ID나 빈 ID는 미등록 슬롯으로 표시하고, 등록된 멤버는 기존 상세로 연결한다.
- 모험가/길드 수와 소식/이벤트는 실제 저장 데이터와 기존 공식 소식을 사용한다. 종료·완료·취소 이벤트는 홈의 진행 목록에서 제외하지만 원본 기록은 변경하지 않는다.
- 기존 SOOP 실시간 API 연동은 없다. 방송국 링크를 제공하고 상태와 시청자 수는 임의로 LIVE/숫자로 표시하지 않는다.

## 책 보존과 모바일 수정

운영 소스와 후보를 각각 별도 서버에서 실행해 동일한 브라우저 임시 데이터로 비교했다. 모험가·길드·월드·연대기·즐겨찾기·라이브·소식·이벤트 8개 경로 × 4개 너비(1536/1100/768/390)에서 책의 HTML, 너비와 내부 카드/필터/정렬/넘김 구조를 비교했다. 상세 팝업 2종의 HTML과 치수도 동일하다. PC 책 내부 픽셀 비교 평균 RGB 오차는 0/255, 모바일의 최대 평균 오차는 0.5/255다.

모바일에서 기존 `.wapControls`가 책 밖의 헤더 뒤에 놓이던 문제는 기존 책의 상단 여백을 기준으로 위치하도록 수정했다. 즐겨찾기는 탭이 추가된 줄 때문에 카드와 겹치지 않도록 700px 이하에서 상단 여백을 40px(360px 이하에서는 56px) 늘렸다. 카드 크기·열 수·양면/세로 전환·정렬·페이지 넘김은 유지한다. 새 여관 스타일을 카드나 상세 내부에 적용하지 않는다.

## 검증

- `python scripts/build.py`: JS 구문, CSS/HTML 에셋 참조, 정적 빌드.
- `python scripts/test_tavern_redesign.py`: 운영 책/상세 보존 비교, 320–2560px 9개 화면 크기, 홈 20칸/실제 집계/방송 링크/예시 데이터 미등록, 모바일 필터 겹침, 공통 검색/메뉴/BGM 음량 저장.
- `python scripts/test_book_ui.py`: 검색·복합 필터·정렬·격자/목록·이전/다음·즐겨찾기·모험가/길드 상세·이벤트/연대기·관리자 저장과 캐릭터 등록.
- `python scripts/test_final_review.py`: 목록 상태 복원, 10개 화면 × 7개 너비, 깨진 이미지 대체, 모달과 차트, 실제 메뉴 클릭, 관리자 모험가/길드/이벤트/연대기 등록·수정·저장 후 새로고침.
- `python scripts/test_book_turns.py`: 7개 경로 × 3개 PC 너비의 넘김 버튼 동일 치수/위치 및 실제 이전/다음, 모바일 넘김.
- `python scripts/test_book_search_visibility.py`: 실제 검색 입력의 픽셀 변화와 하위 모바일 책 프레임 일치.

검수 데이터는 일회용 브라우저 컨텍스트에서만 사용했다. 저장소의 `data/`, `seed`, localStorage 저장 키 `forever-azeroth-v1`/`fa-favs`와 데이터 구조를 변경하지 않았다. 기존 데이터를 삭제·초기화하는 작업은 수행하지 않았다.

BGM 음량 변경/저장은 검증했다. 저장소에 원본 `assets/wow-bgm.mp3`가 없어 실제 음악 재생은 기존과 같이 파일 등록이 필요하다.
