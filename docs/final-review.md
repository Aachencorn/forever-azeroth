## 재현 가능한 검증

```sh
python3 scripts/build.py
python3 -m http.server 4173
# 다른 터미널에서 (Python playwright, /usr/bin/chromium 필요)
python3 scripts/test_book_ui.py
python3 scripts/test_final_review.py
```

- 정적 빌드, JS 구문, HTML/CSS 로컬 자산 경로 검사.
- 검색 입력/커서, 복합 필터, 정렬, 격자/목록, 페이지 경계, 즐겨찾기, 상세 팝업, 소식·이벤트·연대기, 관리자 수정/새로고침 후 저장.
- 10개 화면을 320/390/700/768/900/1024/1536px에서 실제 Chromium으로 확인.
- 이미지 실패 대체 표시, 레벨 구간명, 팝업 가로 스크롤, 태블릿/모바일 메뉴, 팝업 종료 시 목록 상태 복원 검사.
- 관리자 화면에서 신규 모험가·길드·이벤트·연대기 등록과 저장을 검사. 테스트 데이터는 분리된 임시 브라우저에서만 사용하고 종료 시 폐기.
- 고의로 없는 이미지로 대체 표시를 시험한 요청 외에, 로컬 자산 HTTP 오류 및 JavaScript 예외 없음.
- `data/`와 seed에 시안 예시를 추가하지 않았고 기존 저장 데이터를 정리·삭제하지 않음.

## 남는 차이와 기존 기능 범위

시안은 정적 예시이고 실제 화면은 등록 데이터에 따라 렌더링하므로 인물 사진·길드·수치·방송 목록·소식 내용이 다를 수 있다. 에셋을 재제작했으므로 금장·가죽·로고·배너의 화소까지 동일한 복제는 아니다. 작은 화면은 읽기 가능한 단면으로 배치한다.

SOOP 실시간 API는 기존과 같이 미연동이다. 관리자 저장은 기존의 브라우저 localStorage 방식이며 서버 DB나 관리자 인증을 추가하지 않았다. 별도 검수 주소는 기존 사이트 주소에 저장된 브라우저 데이터를 자동으로 가져오지 않는다. 필요하면 기존 JSON 백업/복원 기능을 사용할 수 있다.

검수 사이트는 Sites의 소유자 전용 비공개 호스팅이다. 게시 범위는 정적 배포 파일과 공개 블리자드 소식 링크 JSON 한 개로 제한한다. 사용자 브라우저 저장 데이터·첨부 PNG 원본·Git 기록·비밀은 게시하지 않는다. GitHub `main`과 운영 호스팅 설정은 변경하지 않는다.
