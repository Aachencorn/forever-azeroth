## 원본 일치 교정

이전 재제작 프레임의 형태·배너·로고·책 비율이 원본과 달랐던 문제를 수정했다. `assets/approved/`의 10개 WebP는 사용자 PNG를 크기·색상·화소 변경 없이 무손실 인코딩한 것이다. `exact-design.js`와 `styles/exact-design.css`에서 원본의 장식 영역을 직접 표시하고 데이터가 들어 있는 영역을 마스크로 제외한다. 그 위에 검색·필터·카드·페이지·상세·관리자 기능을 실제 HTML로 렌더링한다. PNG의 예시 인물·길드·시청자 수·소식 레코드는 저장하거나 화면 데이터로 사용하지 않는다.

1536×1024 기준에서 헤더·배너·책등·외곽 프레임 32개 구간을 원본과 직접 비교했다. 가장 큰 구간 평균 RGB 차이는 0.6595/255로, 1534×1025 원본 홈 화면의 미세한 크기 보간을 포함한다. 이는 **장식 영역 검사이며 데이터 영역까지 동일하다는 뜻은 아니다**. 모험가 첫 카드의 좌표와 두 팝업의 위치도 기준 좌표와 비교했다. [측정 결과](approved-artwork-check.json).

재현: `python3 scripts/test_approved_artwork.py` (`APPROVED_SOURCE_DIR`에 PNG 원본 10장의 디렉터리 지정).


- 이미지 실패 대체 표시, 레벨 구간명, 팝업 가로 스크롤, 태블릿/모바일 메뉴, 팝업 종료 시 목록 상태 복원 검사.

- 고의로 없는 이미지로 대체 표시를 시험한 요청 외에, 로컬 자산 HTTP 오류 및 JavaScript 예외 없음.
- `data/`와 seed에 시안 예시를 추가하지 않았고 기존 저장 데이터를 정리·삭제하지 않음.

## 남는 차이와 기존 기능 범위

시안은 정적 예시이고 실제 화면은 등록 데이터에 따라 렌더링하므로 인물 사진·길드·수치·방송 목록·소식 내용이 다를 수 있다. 데스크톱의 로고·배너·책등·외곽 금장·보석은 원본 장식을 직접 사용한다. 실제 레코드를 그리는 HTML 글자·카드·그래프와 비어 있는 종이 영역은 동적으로 렌더링한다. 작은 화면은 읽기 가능한 단면으로 배치한다.

SOOP 실시간 API는 기존과 같이 미연동이다. 관리자 저장은 기존의 브라우저 localStorage 방식이며 서버 DB나 관리자 인증을 추가하지 않았다. 별도 검수 주소는 기존 사이트 주소에 저장된 브라우저 데이터를 자동으로 가져오지 않는다. 필요하면 기존 JSON 백업/복원 기능을 사용할 수 있다.

검수 사이트는 Sites의 소유자 전용 비공개 호스팅이다. 게시 범위는 정적 배포 파일(사용자 승인 원본에서 변환한 무손실 WebP 장식 포함)과 공개 블리자드 소식 링크 JSON 한 개로 제한한다. 사용자 브라우저 저장 데이터·첨부 PNG 원본·Git 기록·비밀은 게시하지 않는다. GitHub `main`과 운영 호스팅 설정은 변경하지 않는다.

## 사용자 제보 후 추가 수정

- 홈 로고 ‘와’의 내부 공간을 어둡게 복원했다. 데스크톱과 모바일 로고에 같은 비율로 적용한다. 원본 WebP 자체는 보존한다.
- 상단 메뉴의 빈 텍스트 높이가 0이 되는 CSS 그리드 문제를 수정했다. 1536/1366/1100px에서 9개 메뉴의 화면 좌표를 실제 클릭하고 이동 경로를 검사한다.
- 상세창의 단색 사각형과 시안 테두리 조각을 겹치는 방식을 제거했다. 원본을 참조해 텍스트·인물 없이 만든 투명 양피지(모험가), 빈 양면 책(길드)을 WebP로 최적화했다. 모바일 길드 상세는 한 장 양피지로 표시하며 내용과 함께 배경이 스크롤한다. 예시 데이터는 등록하지 않았다.
- 10개 화면/7개 너비, 검색·필터·페이지·즐겨찾기·상세 닫기·관리자 등록/수정/저장 회귀 검사와 정적 빌드를 통과했다. 검수 데이터는 브라우저의 임시 저장소에서만 사용했다.

## 책 안쪽 사각 덧칠 제거

메인 와우동 프로필 뒤의 사각 덧칠과 각 페이지의 번호 가림 조각을 제거했다. 장식 마스크는 책의 안쪽 면 전체를 따라가며 경계를 부드럽게 처리하고, 빈 양피지 질감을 하나로 이어 표시한다. 원형 프로필은 사진·빈 슬롯 모두 원형으로 자르고 별도 네모 배경을 두지 않는다. 기록 카드·검색 입력창 등 기능에 필요한 컨트롤은 유지한다. 월드 현황의 빈 데이터 안내가 책 밖으로 넘치던 표시도 수정했다. 예시 데이터와 기존 저장 데이터는 변경하지 않았다.

장식 비교 검사의 즐겨찾기 배너 영역은 y=260까지로 바로잡았다. 이전 y=285 범위에는 이번에 교체한 책 안쪽 양피지 일부가 포함돼 있었다. 원본 이미지의 무손실 검증과 헤더·책등·외곽 프레임 비교는 유지한다.

## 홈 기준 공통 헤더와 화면 비율 수정

모든 화면에서 홈·모험가 도감·길드 도감·월드 현황·포에버 소식·이벤트·연대기·즐겨찾기·라이브의 9개 항목을 같은 순서로 표시한다. 페이지별 시안에 들어 있던 메뉴 그림은 공통 홈 헤더와 실제 링크로 교체했다. 현재 위치만 강조하고 상세 페이지와 관리자에서도 같은 항목을 제공한다.

로고는 홈 원본에서 같은 영역을 표시하며 240:155 비율을 고정했다. 화면별 스프라이트 압축과 중복 표시를 없애고, 작은 화면에서는 음악·메뉴 버튼에 맞춰 로고 폭을 조정한다. 데스크톱은 1100px 이상, 그 미만은 같은 전체 메뉴를 펼치는 방식으로 통일했다. 1001–1099px에서 메뉴가 사라지던 구간도 해결했다. 모바일 항구 배경은 화면을 찌그러뜨리지 않고 비율을 유지해 채운다.

`test_unified_header.py`: 10개 화면 × 10개 크기(320–1920px), 메뉴 순서·상대 위치·로고 비율·겹침/가로 넘침·실제 메뉴 클릭·화면 크기 변경·Escape 닫기 통과. 기존 검색·필터·즐겨찾기·관리자 등록/수정/저장 검사도 통과했다. 원본 아트워크 검사의 헤더 부분은 이제 홈 공통 장식과 비교하며 배너 검사에서는 공통 로고가 겹치는 상단 영역을 제외한다.

## 통합 소식 메뉴·공통 책등·빨간 라이브 아이콘

상단 메뉴의 포에버 소식과 이벤트를 ‘포에버 소식 · 이벤트’ 한 항목으로 합쳐 총 8개 메뉴로 표시한다. 통합 화면의 이벤트 탭과 기존 `/events` 링크는 유지하며, 해당 경로에서도 같은 통합 메뉴를 현재 위치로 강조한다. 작은 화면에서는 긴 통합 메뉴가 한 줄 전체를 사용해 글자가 옆 버튼과 겹치지 않게 했다.

가장 왼쪽 책등은 모든 화면에서 홈 원본의 같은 영역을 표시한다. 데스크톱은 홈 책등 비율을 그대로 맞추고, 모바일은 같은 소스를 일정한 폭으로 이어 표시한다. 라이브 메뉴에는 테마 글자색과 독립된 빨간색 원(`#ef4444`)을 사용한다.

공통 헤더 검사는 10개 화면 × 10개 크기에서 8개 메뉴의 순서·위치, 통합 메뉴 클릭, 이벤트 경로의 강조, 빨간 원 색상, 페이지별 책등 픽셀 일치를 검증한다. 원본 장식 비교의 책등 기준도 각 화면이 아닌 홈으로 통일했다. 기존 데이터와 관리자 저장 방식은 변경하지 않는다.

## 균등 메뉴·양피지 질감·공통 책 넘김

상단 8개 메뉴를 동일한 너비와 높이로 조정했다. 긴 소식·이벤트 문구는 버튼 내부에서 두 줄로 배치하며 모바일 메뉴 역시 같은 크기의 버튼으로 표시한다. 와우동 20인 배경은 빈 양피지 에셋의 주름·섬유·낡은 가장자리가 드러나도록 표시 범위를 조정했다.

책 하단까지 내려오던 양피지 바탕을 안쪽으로 줄이고, 빈 가죽 테두리와 부드럽게 이어지게 했다. 페이지 번호를 가리는 별도 사각 덧칠은 사용하지 않는다. 즐겨찾기 오른쪽에서 원본 예시 카드의 가장자리가 조금 노출되던 마스크 범위도 수정했다.

모험가·길드·즐겨찾기·라이브·소식/이벤트·연대기의 데스크톱 넘김 버튼은 하나의 공통 하단 배치를 사용한다. 실제 페이지 변경 액션과 페이지 수는 기존 컨트롤에서 유지하며, 작은 화면에서는 기존 책 안쪽 컨트롤을 표시한다. `test_book_turns.py`는 7개 경로 × 3개 너비에서 이전/다음 버튼 좌표와 크기 일치, 실제 페이지 이동과 번호 변경, 모바일 전환을 검증한다. 공통 헤더 검사에는 모든 버튼의 너비·높이가 같은지도 추가했다. 장식 비교의 오른쪽 프레임 검사는 공통 하단 가죽 영역이 시작되기 전까지 유지한다.
