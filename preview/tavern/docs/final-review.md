# 와포북 공통 책 디자인 검수

대상: `Aachencorn/forever-azeroth`의 `design/final-book-ui`. `main`에는 반영하지 않는다.
미리보기: https://wapobook-final-review.aptjoy10.chatgpt.site

## 현재 적용 구조

모든 상단 메뉴는 한 개의 빈 책 원본(`assets/wapobook/clean-open-book.webp`)을 사용한다. 페이지별 PNG에 포함된 테두리·보석·제본·필터 그림을 마스크로 섞던 구조를 제거했다. 상단 배너의 풍경/제목만 각 원본에서 따로 표시하고, 검색과 필터는 실제 HTML 컨트롤을 사용한다. 책의 시작점·양피지·금장·보석·중앙 제본·하단 프레임은 화면을 이동해도 바뀌지 않는다.

메인도 같은 책 프레임 안에 소식 패널과 와우동 20인 슬롯을 배치했다. 모바일에서는 모든 메뉴에 같은 테두리 이미지·두께·양피지 바탕을 적용한다. 모바일 배너는 컨트롤이나 책 장식이 그려져 있지 않은 풍경 에셋을 사용해 배너 하단에 옛 책 보석/필터가 남지 않게 했다. 길드 상세 책도 같은 원본의 책 영역을 사용한다. 모험가 상세의 한 장 양피지는 승인된 상세 형태를 유지한다.

## 화면별 검수

| 화면 | 수정 및 확인 |
| --- | --- |
| 메인 | 공통 책 프레임으로 정렬. 기존 3개 패널과 20개 프로필 링크·빈 슬롯·검색 유지 |
| 모험가 도감 | 공통 프레임·검색·필터·정렬·그리드/목록·넘김·상세 확인 |
| 길드 도감 | 공통 프레임·필터 기준선·길드 카드·통계·상세·넘김 확인 |
| 월드 현황 | 같은 양피지와 제본 사용. 빈 데이터 안내와 분포 수치·레이블 확인 |
| 소식·이벤트 | 같은 프레임·탭·검색·목록/상세·원문 링크·넘김 확인. 기존 이벤트 경로 유지 |
| 연대기 | 같은 프레임·분류·목록·선택 상세·넘김 확인 |
| 즐겨찾기 | 짧은 옛 책 그림 제거. 탭·필터·카드·정렬을 공통 책 영역 안으로 이동. 저장/빈 결과 확인 |
| 라이브 | 옛 책 상단/필터 그림 제거. 공통 필터 기준선과 카드 영역 사용. 카드 하단 잘림 수정 |
| 상세 팝업 | 모험가/길드 상세의 닫기·즐겨찾기·다른 캐릭터·멤버·모바일 스크롤 확인 |
| 관리자 | 기존 등록·수정·저장·새로고침 후 유지 회귀 검사. 관리자 데이터 모델은 변경하지 않음 |

검수 중 배너의 격리된 레이어가 실제 검색어를 가리고 있던 문제를 수정했다. 데스크톱 검색창을 같은 위치와 모양으로 정리하고, 입력 전후의 실제 화면 픽셀 차이로 검색 글자가 보이는지도 검사한다.

## 검증

- `scripts/build.py`: 정적 빌드와 JavaScript 구문·에셋 참조 검사.
- `scripts/test_approved_artwork.py`: 승인 원본 10장의 무손실 보존, 9개 경로 × 책 프레임 5개 구간(45개) 비교, 카드 및 상세 위치 검사. 측정 결과는 [approved-artwork-check.json](approved-artwork-check.json). 최대 구간 평균 RGB 차이는 약 0.11/255다.
- `scripts/test_book_search_visibility.py`: 4개 검색 화면 × 2개 데스크톱 너비에서 입력한 글자의 실제 픽셀 변화 검사. 8개 메뉴 × 4개 모바일 너비에서 같은 테두리/양피지인지 검사.
- `scripts/test_unified_header.py`: 10개 화면 × 10개 크기(320–1920px), 같은 8개 메뉴·균등 버튼·로고·책등·빨간 라이브 원·BGM 위치와 음량 저장·실제 메뉴 이동 검사.
- `scripts/test_book_turns.py`: 7개 경로 × 3개 너비에서 넘김 버튼 위치·크기·실제 이전/다음 동작과 모바일 전환 검사.
- `scripts/test_book_ui.py`, `scripts/test_final_review.py`: 검색·복합 필터·정렬·페이지·즐겨찾기·상세 상태 복원·관리자 등록/수정/저장, 10개 화면/7개 너비, 깨진 이미지 대체와 가로 넘침 검사.
- 실제 데이터가 없는 화면과 브라우저 임시 검수 데이터가 채워진 화면 모두 비교했다. 검수 예시를 저장소 데이터나 배포 데이터에 등록하지 않았다.

실제 오디오 파일 재생 여부는 이번 디자인 검수 범위에 포함하지 않는다. BGM 컨트롤의 위치·음량 조작·저장 동작은 검증한다.
